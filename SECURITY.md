# Security / Sécurité

Please report vulnerabilities privately through GitHub's **Report a vulnerability** option for this repository. Do not put exploit details in a public issue. Maintained releases: 0.2.x. We aim to acknowledge reports within seven days.

Signalez les vulnérabilités par l’option privée **Signaler une vulnérabilité** de GitHub pour ce dépôt. Ne publiez pas les détails d’exploitation dans une issue publique. Versions maintenues : 0.2.x. Nous visons un accusé de réception sous sept jours.

Action profiles can open links and files and simulate keyboard input. Only import profiles you trust. Decklight does not execute shell commands and has no telemetry or server component.

Stream Deck archives are parsed locally with limits on archive size, extracted data and image size. Original plugin action settings are retained in local profile data and included in Decklight JSON exports; these settings may contain access tokens or other credentials. Keep exported files private and review imported actions before running them.

Les archives Stream Deck sont analysées localement avec des limites de taille. Les réglages originaux des plugins sont conservés dans les profils locaux et dans les exports JSON Decklight ; ils peuvent contenir des jetons ou d’autres identifiants. Gardez ces fichiers privés et examinez les actions importées avant de les lancer.
