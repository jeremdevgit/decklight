# Security / Sécurité

Please report vulnerabilities privately through GitHub's **Report a vulnerability** option for this repository. Do not put exploit details in a public issue. Maintained releases: 0.1.x. We aim to acknowledge reports within seven days.

Signalez les vulnérabilités par l’option privée **Signaler une vulnérabilité** de GitHub pour ce dépôt. Ne publiez pas les détails d’exploitation dans une issue publique. Versions maintenues : 0.1.x. Nous visons un accusé de réception sous sept jours.

Action profiles can open links and files and simulate keyboard input. Only import profiles you trust. Decklight does not execute shell commands and has no telemetry or server component.
